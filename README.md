# Java DSA & LeetCode Solutions

Daily DSA practice and LeetCode solutions in Java, prepping for software developer interviews.

## Structure
Organized by topic — Arrays, Strings, Math, etc.

## About the code
These are written in LeetCode's submission format (a `Solution` class with the method LeetCode expects) — they're not meant to run standalone. To verify any solution:
1. Copy the `Solution` class into LeetCode's editor for the matching problem, or
2. Wrap it locally with a small `main` method that creates a `Solution` object and calls the method with a test input
